### 2.2 The brief's `STZ $sr,S`, refuted by the same table [REFUTED]

`grep "'STZ'" snesrecomp/recompiler/snes65816.py` returns exactly **two** rows:


**`0x63` is `ADC STK`, not `STZ STK`.** The brief's premise — that `0x9C` is a stack-relative

`STK` group, and `STZ` is not in the `STK` group at all. **A wrong S cannot redirect this
store, because the store contains no S.**

## 7. The S thread [REFUTED as a lead; the observation itself stands]

cannot redirect this store, because the store has no S in it.

explains `$03:8222`.
