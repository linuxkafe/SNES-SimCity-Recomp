### R-01 — BLOCKER — `make test` reports PASSED for a test that did not run

**Persona:** Cínico. **Rubric:** C-04, C-05, G-01, E-05.

```
$ cd /tmp/opencode/reloc4/simcity        # relocated copy, zero .sfc files, built clean
$ env -u SIMCITY_ROM make test
1/2 Test #1: test_deterministic_replay ........   Passed    0.01 sec
2/2 Test #2: test_display_aspect ..............   Passed    0.01 sec
100% tests passed, 0 tests failed out of 2
$ ctest >/dev/null 2>&1; echo $?
0
```

`tests/test_deterministic_replay.c:76-81` prints `SKIP: no ROM found` and
`return 0;`. `CMakeLists.txt:125` registers the test with no
`SKIP_RETURN_CODE` property, so ctest renders the skip as **Passed**.

**This is a regression of the substance of the previous review's BLOCKER F-02.**
F-02's letter was closed — `grep -rn '/home/seyon' tests/` now finds only a
*comment explaining the fix*, and the test resolves its ROM from `$SIMCITY_ROM`
then from beside the build. Its **substance** was "a tree with no ROM reports
2/2 passed". That is still exactly what happens, by a different route. A closure
condition was satisfied while the defect it described survived the fix.

**And the criterion that should have caught it cannot.** C-04's verifiable check
is `cp -r . /tmp/relocated && cd /tmp/relocated && make build && make test` —
which copies the ROM, which the project's own legal rule forbids, so the check is
not executable as written (the previous review said so). The closest legitimate
equivalent is what was run here, and it found a real defect the written check
would have masked.

**Closure:** with no ROM resolvable, `ctest` exits non-zero or prints `Skipped`,
and `make test` propagates that as a failure.
`cd <relocated tree, no ROM> && ctest; echo $?` must not be 0 alongside `Passed`.

**Stated precisely, because the reviewer got this wrong first.** In a tree that
**has** a ROM, the test genuinely runs and passes:

```
$ cd build && env -u SIMCITY_ROM ctest -R test_deterministic_replay -V
1: Using ROM: ../SimCity (USA).sfc
1/1 Test #1: test_deterministic_replay ........   Passed    1.28 sec
```

The vacuous pass happens **only where no ROM exists** — which is every developer
who has not supplied one, and the relocated tree the rubric's own C-04 check
calls for. `docs/DEFINITION_OF_DONE.md` D4.1/D1.2 count `make test` as a
criterion, and on such a machine it is satisfied without running anything.

## Protocol deviations, stated rather than hidden

1. **No independent reviewers, again.** The protocol requires 2+ reviewers from
   different model families, or a fallback convening four personas as **fresh
   subagents**. **This session has no subagent tool.** All four personas were run
   by one model in one context, each writing its findings to a separate file
   before the next was written. That preserves *non-sharing of findings*; it does
   **not** preserve independence of judgement. Per the protocol's own enforcement
   rule, **this review is a valid single-reviewer review with a multi-perspective
   supplement — not a valid multi-perspective review.** The BLOCKERs do not depend
   on it: R-01, R-02 and R-03 are each independently verifiable by the commands in
   their evidence blocks, by anyone with a shell and the ROM.

2. **Three of the skill's four required files do not exist here.**
   `docs/PEER_REVIEW.md` — absent. `docs/review/MULTI_PERSPECTIVE_REVIEW.md` —
   absent. `templates/review-rubric.md` — the skill directory ships `SKILL.md`
   only. The protocol therefore could not be read in full, and this review follows
   the protocol as described *inside `SKILL.md`*. **The skill's own rubric was not
   substituted**, for the reason the previous review gave and which still holds:
   it is `NARRATIVE-INTEGRITY-SUITE`, about the AES toolkit's shell scripts, and
   under it R-02 and R-03 would have scored as *good practice* — "retract a claim
   whose evidence failed" is textbook hygiene. **The substitution would not have
   changed the verdict; it would have inverted the reasoning.**

3. **Human validation is outstanding.** `docs/review/validate-findings.sh` exists
   and validates the *previous* review. **It has not been extended to these
   findings and has not been run by anyone other than the author.** Until it is,
   these findings are unconfirmed by the protocol's own standard, even though

4. **This review's candidate includes the reviewer's own preceding phases.** The

## The one measurement this review most wants next

Not a cause. **A gate that cannot be wrong about itself.**

result it did not produce.* The test reports PASSED without running; the

that a test which reports SKIP makes its target fail.** Not a threshold. Not a
wider margin. A check that the report matches the work.
